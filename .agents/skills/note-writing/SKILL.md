# Note Writing

Apply the shared conventions to both note types, then use the rules for the type being written. Theory/math learning notes develop the mathematical understanding; implementation companions explain working software that applies it. Theory-specific derivation and quiz requirements do not apply to implementation companions.

## Read the applicable rules

- For either note type, read [Shared conventions](references/shared.md), including the review cadence and fast interactive review rule.
- For theory/math learning notes, also read [Theory/math learning notes](references/theory.md).
- For implementation companions, also read [Implementation companions](references/implementation.md).
- When writing or editing LaTeX, also read [Quarto and LaTeX rendering](references/quarto-latex.md).

Repository paths mentioned in these references are relative to the repository root.
